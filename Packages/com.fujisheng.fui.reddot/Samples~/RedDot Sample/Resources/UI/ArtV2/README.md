# Frontier Command 美术资源

本目录是 Red Dot Sample 的原创科幻 RTS 界面资源，不包含第三方游戏截图、Logo、角色、字体或临摹素材。

## 制作流程

1. 为主基地、单位、仓库、任务、通讯和航程分别生成 1920×1080 设计母图，先确定页面构图和视觉层级。
2. 以设计母图和统一色板为参考，生成共享面板、按钮、槽位、进度条、红点皮肤，以及各页面的主题插画和图标。
3. 对透明资源执行 Alpha 或色键后处理，并校验目标尺寸、透明范围和色键残留。
4. 由 FUI CLI 从 HTML 提取 `visual-ui.json`，再通过 `ui.web_to_ugui_prefab` 生成六个独立 Prefab。

设计母图只用于设计参考，不作为整屏图片进入运行时。运行时文字仍由 Unity Text 渲染，按钮和红点仍是独立 FUI 元素。

## 目录

- `Shared`：背景、面板、主次按钮、导航卡、物品槽、进度条、红点和返回图标。
- `GameHomeView`：指挥官头像、战略地图和五个入口图标。
- `HeroView`：侦察平台和三种无人机图标。
- `BagView`：补给箱、合金、数据核心和能源电池。
- `QuestView`：行动地图、前哨和矿区缩略图。
- `MailView`：通讯中继场景和发送者图标。
- `SeasonView`：边境航程路线图。

所有图片均由本项目使用内置图像生成工具制作，并经过人工目视检查；资源仅用于本开源 Sample。
