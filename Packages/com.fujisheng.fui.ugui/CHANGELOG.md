# Changelog

All notable public changes to `com.fujisheng.fui.ugui` are documented here. Versions follow Semantic Versioning.

## [1.0.0] - 2026-11-03

### Added

- 从 com.fujisheng.fui 抽离 uGUI 运行时渲染层，建立独立的 `com.fujisheng.fui.ugui` 包。
- 包含 `FUI.Rendering.UGUI` 程序集：`View` 基类、内置 `Element`、资源加载契约与 uGUI 工具。
- 依赖 `com.fujisheng.fui` 2.0.0 与 `com.unity.ugui` 2.0.0。
