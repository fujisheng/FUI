# Editor Setup

## Setup

`Tools/FUI/Setup` 为目标程序集安装 Source Generator，按需安装 Mixed 模式 Cecil，并显示可从 OpenUPM 安装的可选生态 Package。

## Binding Inspector

Binding Inspector 在 Edit Mode 显示生成的 View 与 ViewModel 连接，可定位对象并跳转源码。

可选 Package 也显示在 Setup 中，但始终保持独立 UPM 依赖。Prefab 创建与验证见 [Page Wizard 与验证](validation.md)。
