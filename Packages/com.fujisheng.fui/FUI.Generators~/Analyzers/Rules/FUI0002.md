# FUI0002

## Target property 'xxx' not 'FUI.Binding.BindableProperty<>'

This error occurs when the target property is not inherited from FUI.Binding.BindableProperty&lt;T&gt;.

```c#
[Bind("txt_test", nameof(TextElement.name))]
public string TestString{get; set;} => string.Empty
```

The TextElement.name is not inherited from FUI.BindingProperty&lt;T&gt;.

The following example resolves the error:

```c#
[Bind("txt_test", nameof(TextElement.Text))]
public string TestString{get; set;} => string.Empty
```
