# Settings Sample

This sample demonstrates generated binding, two-way controls, typed navigation, Presenter initialization, and exact ViewHandle ownership without external assets or optional packages.

1. Import the sample from Package Manager.
2. Open `Scenes/SettingsSample.unity`.
3. Wait for compilation to finish.
4. Enter Play Mode.

The sample includes a package-matching copy of `FUI.Generators.dll` scoped to its assembly so generated Routes are available immediately. Production assemblies should install the Generator through `FUI/Setup`.
